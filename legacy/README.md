# Legacy ASE Sources

This directory preserves the recovered ASE manuscript sources, bibliography files, README, and images as received. The revised FSE manuscript does not compile files from this directory.

The root-level project is the clean, non-roundabout revision. Keep this directory unchanged so passages, tables, citation metadata, and original figures can be recovered if needed.

For ZIP/Overleaf filename portability, the original image `wf - 副本.png` is stored as `imgs/wf-copy-original.png`; its file contents are unchanged.
